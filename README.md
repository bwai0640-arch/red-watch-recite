# 凛冬督学局

“凛冬督学局”是 Windows 64 位沉浸式学习监督桌面应用。背书模式通过本地声纹确认本人朗读，自习模式在本机区分键盘输入与持续的人声、音乐、视频和游戏等媒体声音；教官动画会在完整场景、漂浮窗和后台状态之间连贯巡查、提醒与表扬。

打开即可使用，声音分析在本机完成，应用仅请求麦克风权限。完整上手流程见 [使用说明](docs/USER_GUIDE.md)。

作者角色与署名边界见 [作者与署名](AUTHORS.md)，媒体素材的来源和公开边界见 [资产来源与权利说明](docs/ASSET_PROVENANCE.md)。

当前源码版本为 1.13.3，发布日期为 2026-07-27。

## 本地成品与 GitHub 仓库

本地交付物构建在 `release-staging/`：安装版为 `凛冬督学局-安装版-<version>.exe`，便携版为 `凛冬督学局-便携版-<version>.exe`。GitHub 仓库包含构建所需源码、22 段动画、22 份对应源音轨、应用图标、本地声纹模型和本地音频事件模型；EXE 不直接提交进 Git 历史。

`.gitignore` 默认排除 `node_modules/`、`dist/`、`release-staging/`、所有 `RedWatchReciteData/`、任意 `speaker-profile.dat*` 与 `study-preferences.json`、本地 `work/`、真实 `.env`、日志和缓存。真人测试语音、加密声纹、用户运行数据及本地审查产物不会进入公开仓库。该策略只防止未跟踪文件被首次加入；若文件已经进入 Git 历史，仍须另行清理历史并重新审查。

不要移动、提交、分享或清理 `%APPDATA%\背书自习监督` 中的 `speaker-profile.dat`；它可能是用户真实录入的加密声纹。1.13.0 虽将可见产品名改为“凛冬督学局”，仍刻意沿用这个旧数据目录，避免升级后丢失或重复录入声纹；这不是仍在使用旧产品名。公开仓库、commit 历史和 Release 附件都不得包含声纹档案、用户运行数据或真人测试录音。

`window-preferences.json` 只保存后台方式 `backgroundMode` 和漂浮尺寸 `floatingWindowSize`，不保存窗口位置、检测结果、学习时长、音频、声纹或其他个人数据。

`study-preferences.json` 除固定格式版本外，只保存模式 `mode`、背书 20～60 秒提醒时间、自习 3～15 秒持续时间，以及用户选定麦克风的 `deviceId`/`label`。它不含音频、声纹、检测结果、学习记录或计时；设备标签即使带有用户自定义名称也只留在本机。选定设备缺失时应用保留原选择并明确提示，不会按同名设备或系统默认设备自动替换。

背书的声音前置筛选不再保存或暴露“底噪/抗噪”参数：内部固定使用 8 dB 余量。旧设置中的 `reciteSensitivityDb` 会被忽略，并在下次保存设置时移除。

## 核心行为

- 可在检测面板选择用于测试、学习与录入的麦克风；选择会仅保存在本机。
- 可为同一人保存最多 5 份麦克风/环境声纹模板。每份模板均通过麦克风连续录入 24 秒生成，运行时会分别匹配，任一模板达到原声纹阈值即可，不会把不同环境模板平均后互相稀释。
- 开始学习前可在检测面板测试当前设置；测试复用对应模式的正式判定链路，但不计时、不播放动画或音轨，也不触发提醒。背书只需试调 20～60 秒的未检测到本人提醒时间，不提供底噪、抗噪或手动重校准。
- 背书与自习的主界面活动条只用于确认麦克风正在收到声音，不显示白色门槛线，也不能作为底噪控制；漂浮窗不显示音量条或调节滑块。
- 背书底层自动适应环境声音，以高召回 VAD 切出疑似语音，再由本地 CAM++ 声纹模型作最终判断；高置信本人声音最快约 2 秒确认，模糊片段仍走完整 2.4 秒复核，正式阈值不因加速而降低。只有确认到本人的声音才清零静默计时。提醒阈值可在 20～60 秒内调节，学习中修改也不会清空已经累计的未确认时长或在途声纹候选。
- 背书开始及休息恢复后的前约 3 秒用于自动环境适应，无需保持安静。若这段时间已经开始朗读，检测器会采用保守噪声上限，适应结束后应在 300 ms 内重新形成疑似语音候选，避免把本人朗读学成底噪。
- 自习模式不要求声纹，也不做 3 秒环境底噪校准或音量门槛筛选；本地 CED Mini 分析最近约 2 秒声音，首窗约需 2 秒、之后约每 1 秒更新。人声使用 0.12 专用阈值，音乐/通用媒体使用 0.20 阈值，并覆盖电视、广播、游戏与常见媒体音效。单独键盘声不累计；候选出现孤立漏检窗口时保留原累计，只有连续正常 5 秒才清除。用户只调 3～15 秒媒体持续时间。
- 背书每 20 分钟、自习每 45 分钟获得一张 2 分钟休息券；可立即休息或在本次会话内攒下。
- 背书每 45 分钟、自习每 60 分钟播放一次带源音轨的表扬序列，并显示不遮挡教官的字幕。
- 正常巡查、观察和路过静音；开场、结束、违规、表扬及休息结束后的开场播放对应动画自己的源音轨。
- “隐藏到后台”按钮悬停或键盘聚焦后可直接选择“完全隐藏 / 使用漂浮窗”，检测面板也保留同一设置。漂浮窗复用同一个主窗口，常态只显示当前判断和 16:9 小动画；只有进入红色异常状态后，原判断才显示累计秒数，正常和未达阈值状态没有额外计时。鼠标移入时才显示“已学习 00:00”、“隐藏”和“放大”；其中“隐藏”会完全隐藏到后台。除操作按钮外的漂浮区域均可自由拖动；窗口由 Windows 原生缩放在 224×170～320×225 间调整并记住尺寸，缩放和拖动过程中不强制改写鼠标下的窗口位置。漂浮窗不再支持双击放大，只能点击“放大”。违规会把同一窗口恢复为完整场景，提醒结束后回到原后台方式。只有休息券使用一个右下角独立提示窗。
- 场景按 1920×1080 等比例展示，屏幕不足时整体缩小，不拉伸源动画。
- 主窗口可拖动和缩放；右上角依次为最小化、最大化/还原、隐藏到后台，双击标题栏也可最大化/还原。完整场景安全最小尺寸为 960×540；漂浮模式使用独立的 224×170～320×225 范围，置顶且不显示任务栏按钮。

## 开发环境

依赖版本由 `package.json` 和 `pnpm-lock.yaml` 固定：

- Electron 43.1.0
- electron-builder 26.15.3
- sherpa-onnx-node 1.13.4
- CAM++ 本地声纹模型
- CED Mini 本地音频事件模型

CED Mini INT8 ONNX 取自 k2-fsa/sherpa-onnx 音频标签模型转换包。该包 README 只说明转换自 RicherMans/CED，没有明确精确 checkpoint 与转换文件的逐文件许可；项目因此不把任一上游页面的许可直接写成该 ONNX 的确定许可。哈希、相关上游声明与公开分发限定见 [第三方软件声明](THIRD_PARTY_NOTICES.md) 和模型目录中的 `SOURCE_README.md`。

当前已验证的开发环境为 Node.js 24.14.0 与 pnpm 11.7.0；Electron 43.1.0 要求 Node.js 至少为 22.12.0。请使用 Node.js 22.12.0 或更高版本，并确保 `node` 与 `pnpm` 已加入 PATH。

在 Node.js 已加入 PATH 的普通开发机上：

```powershell
cd <仓库目录>
pnpm install --frozen-lockfile
pnpm start
```

公开仓库包含运行与构建所需媒体、图标和模型，但不包含 `work/speaker-fixtures/` 中的本地真人测试语音，也不提交音频事件模型的临时正样本。依赖匿名本地 fixture 的声纹模型测试只供维护者在合规数据准备完成后运行。1.13.3 已通过纯后台语法、窗口策略和源码门禁；按用户要求没有启动 Electron、UI/CDP、候选 EXE、真实麦克风或用户声纹，因此不能把后台结果写成真实 UI 实测通过。候选包与附件隐私结论以本轮隔离构建和最终扫描为准。

## 构建

不要在已经含有用户数据的 `dist` 或 `release-staging` 上直接运行 `pnpm dist`；electron-builder 可能清理输出目录。正式构建必须先输出到 `work/` 下全新的隔离候选目录，验证通过后再只把两个 EXE 和说明书复制到 `release-staging`，完整流程见 [发布清单](docs/RELEASE.md)。

公开仓库包含完整媒体和图标，可按上述流程启动并构建。正式 `凛冬督学局.exe` 不提交到 Git 历史，后续作为 GitHub Release 附件单独提供。

## 源码导航

| 路径 | 职责 |
|---|---|
| `main.js` | Electron 主进程、主窗口、休息提示窗、托盘、本地协议、权限、声纹与音频事件 IPC |
| `window-mode-policy.js` | 后台偏好校验与持久化、提醒返回模式和漂浮窗多屏几何 |
| `study-settings-policy.js` | 模式、两个时间范围和选定麦克风的本地白名单设置校验与原子持久化 |
| `preload.js`、`break-prompt-preload.js` | 分别向主页面与休息提示页暴露相互隔离的最小 API |
| `renderer/app.js` | 双模式用户流程、VAD、声纹复核、休息与场景总状态机 |
| `renderer/study-policy.js` | 模式阈值、有效学习时钟、休息/表扬里程碑和安静自习判定 |
| `renderer/scene-rules.js` | 动画计划、巡查池、里程碑表扬和三级违规的唯一事实源 |
| `renderer/media-player.js` | 精灵图、源音轨和无黑屏连续播放 |
| `speaker-service.js` | 声纹档案、阈值、加密、原子写入和 Worker RPC |
| `profile-crypto.js` | 通过当前 Windows 用户的 DPAPI 加密/解密声纹档案；明文仅经子进程标准输入传递 |
| `speaker-worker.js` | Sherpa/CAM++ 推理、音频质量和动态检查 |
| `audio-event-service.js`、`audio-event-worker.js` | CED Mini 本地音频事件推理与隔离的 Worker RPC |
| `scripts/` | 静态、声纹、音频事件、媒体和 UI 对抗测试 |
