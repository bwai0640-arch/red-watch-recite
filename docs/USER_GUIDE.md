## 2. 选择模式

主界面顶部可选择：

- **背书**：需要先录入本人声纹。只有本机确认是你本人说话，才算正在背书。
- **自习**：不要求录入声纹。目标是安静学习，本机声音分类模型会区分单独键盘声与持续的人声、音乐、电视/广播、游戏等媒体声音。

一场学习开始后不能切换模式；结束后再选择另一种模式。主界面底部的出声检测条在面板展开或收起时都会保留，可以直接看到当前状态、持续时间和麦克风活动强度；自习模式显示的是原始 RMS 活动强度。

背书模式音量条上的白色竖线是检测门槛：可直接拖动或用方向键粗调，并与检测面板的“抗噪幅度”同步。自习模式隐藏白线和抗噪滑块；音量条只展示麦克风原始 RMS，让你确认麦克风有活动，不参与 CED Mini 分类结果。

## 3. 背书模式：首次录入本人声音

首次进入背书模式并点击“开始学习”时：

1. 页面打开“录入本人声音”。
2. 点击“开始 24 秒录入”。
3. 先在检测面板选择平时背书使用的麦克风，再以相同距离和音量连续朗读任意内容。
4. 显示“本人声纹已保存”后，再次点击“开始学习”。

录入页只允许直接麦克风录入，不提供音频文件导入。每个账户最多可保留 5 份本人声纹模板，适合登记不同麦克风或常用环境；检测时任一模板匹配即可。选择模板后可单独删除，不会影响其余模板。
同一应用数据目录中的旧单份声纹会显示为“原有声纹”；只有在新增或删除模板时，才会写入新版模板档案。

录入建议：

- 24 秒内尽量持续朗读，不要只说几个字或长时间停顿。
- 保持日常风扇、空调环境，但不要让风直吹麦克风。
- 不要同时播放游戏、短视频、电视或音乐，也不要让旁人同时说话。
- 换过麦克风、房间，或本人声音状态变化明显时，可先在检测面板切换麦克风，再点击“新增当前麦克风声纹”；不必删除原有模板。

程序从录入内容中提取 8 个候选片段，自动保留最一致的 6 个加密声纹特征。原始 PCM 不写盘、不上传，也不会生成录音文件。

## 4. 开始前测试检测设置

先在检测面板的“麦克风”下拉框选择设备；点击“刷新”会请求一次麦克风权限以显示完整设备名称。所选设备同时用于待命测试、正式学习和声纹录入。若设备断开，应用会提示重新选择，不会静默改用另一支麦克风。

不必先开始一场学习。点击“展开检测面板”，即可一边调整滑块一边测试当前麦克风环境：

1. 先选择“背书”或“自习”。背书测试使用正式声纹验证，因此没有声纹时应先点击“录入本人声音”；自习测试无需声纹。
2. 背书设置“未出声提醒”和“抗噪幅度/出声门槛”；自习只设置“持续出声提醒”，不需要也看不到抗噪门槛。
3. 在“后台显示”选择“完全隐藏”或“漂浮窗”。该选择会保存在本机，默认“完全隐藏”。
4. 点击“测试当前设置”，允许应用使用麦克风。
5. 背书先保持平时环境声音约 3 秒完成底噪校准；自习不校准底噪，点击后直接收集最近约 2 秒声音形成首个分类结果。
6. 按平时方式背书或安静自习，观察详细状态和麦克风活动条；只有背书会显示音量门槛，自习只显示原始 RMS。
7. 测试中可继续调整当前模式可见的设置。背书门槛实时生效；自习改变持续时间会清除旧分类窗口和在途旧结果，再等待约 2 秒首窗并从头累计。

测试复用正式学习的麦克风和对应模式链路：背书走约 3 秒底噪校准、VAD 与本地声纹验证，并保留最多 3 秒在途验证宽限；自习绕过底噪和音量门槛，直接走 CED Mini 滚动分类/累计，首个有效分类约需 2 秒，之后约每 1 秒更新。达到条件时只显示“按当前设置将触发提醒”，不会播放提醒动画、音效或改变正式学习记录。

点击“停止测试”会立即释放麦克风。直接点击“开始学习”时，程序也会先安全停止测试，再用一条新的正式检测流开始会话；切换模式、打开声纹录入、预览动画、最小化、完全隐藏、进入漂浮窗、退出程序或麦克风断开同样会停止待命测试。这样可以避免测试在后台悄悄占用麦克风。

## 5. 开始学习

1. 选择“背书”或“自习”。
2. 按需要调节提醒阈值。
3. 点击“开始学习”，允许桌面应用使用麦克风。
4. 开场按 `E1 入场 → S1 开班训话 → X1 退场` 连贯播放，并播放各段对应的源音轨。
5. 背书在开场结束后保持平时环境声音约 3 秒完成底噪校准；自习不做这一步，开场后直接进入学习并形成约 2 秒首个分类窗口。
6. 背书校准完成后开始检测；自习约每 1 秒更新分类结果。

开场、校准、提醒、表扬、休息和结束动画都不计入有效学习时长。程序自己的动画音轨也不会被算作用户出声。

## 6. 背书模式检测与提醒

背书的“未出声提醒”可在 **20～60 秒**之间调节，步长 5 秒，默认 20 秒。

运行时先用自适应 VAD 筛选疑似语音，再在本机用声纹模型确认说话者。只有确认到本人声音才会清零静默计时；风扇、游戏、短视频、电视和旁人说话即使使音量条变化，也不能只靠音量通过。

声纹判断需要约 2.4 秒连续声音：

- 分数很明确时，一次判断即可确认。
- 临界声音会综合最近三次判断，至少两次命中才确认。
- 单次失败不会立即显示“不是本人”；连续多次无法确认才显示“暂未确认本人声音”。
- 阈值到达时如果正在收集或验证候选声音，最多宽限 3 秒等待结果。

连续达到所选时长仍未确认本人声音时，提醒按本次会话累计升级：

1. 第 1 次：随机入场 → `R1_react_yell` 严厉训诫 → 随机退场。
2. 第 2 次：随机入场 → `R_aim_react_gun` 举枪警告 → 随机退场。
3. 第 3 次：随机入场 → 50% `R_aim_shoot` / 50% `R_whip_react_lash`；本次学习结束。

第 1、2 次提醒结束后重新开始一轮计时；确认到本人声音只清零当前静默时间，不清除已经累计的提醒等级。新开一场学习才恢复到第 1 级。

## 7. 自习模式检测与提醒

自习模式用于安静阅读、做题或使用电脑学习，不需要声纹。媒体声音提醒阈值可在 **3～15 秒**之间调节，步长 1 秒，默认 8 秒。

自习模式不创建或使用 `AdaptiveVad`，不校准环境底噪，也不使用音量门槛。麦克风打开后直接在本机用 CED Mini 分析最近约 2 秒声音，首次有效分类约需 2 秒，之后约每 1 秒更新：

- 只识别到键盘、打字等标签时不累计违规。
- 键盘很响时，如果同一窗口里仍出现两项媒体证据，媒体证据继续累计，不能用键盘声把视频或音乐自动放行。
- 人声、音乐、电视、广播、游戏等媒体证据达到阈值后，会进入与背书相同的三级提醒。
- 媒体证据必须连续；任一阴性分类窗口都会立即清空本轮候选，后续媒体需从头累计。
- 连续阳性会先抵扣约 1 秒窗口重叠，因此同一段约 2 秒声音不会因为同时出现在三个窗口里而被算成 3 秒；连续媒体通常会比滑块数值晚约 1 秒确认。

自习模式会请求关闭回声消除、系统降噪和自动增益，避免电脑扬声器的视频声先被系统消掉；部分麦克风驱动或硬件可能仍强制开启这些处理，程序会提示，但无法绕过驱动。模型属于概率判断：极端响键盘仍可能掩盖媒体，合法课程、旁人说话或其他持续音频也可能被判为媒体。可先用“测试当前设置”边播放日常环境声边调节阈值。

## 8. 主界面出声状态

主控制区按钮下方始终显示实时检测条：

- 背书模式显示“本人出声检测”，区分检测到声音、正在复核、已确认本人和本人未出声时长。
- 自习模式显示“安静检测”，展示分类暖机、键盘、媒体证据及已累计时间。
- 左侧状态文字、进度条与展开检测面板中的详细音量条使用同一份实时数据。
- 背书的常驻条和详细条带可拖动白色门槛线，并与抗噪滑块同步；自习只显示原始 RMS 活动条，不显示门槛线。

音量条变化只代表麦克风检测到了能量，不等于背书模式已确认本人，也不等于自习模式已经违规。

## 9. 休息券

只按有效学习时长发放两分钟休息券：

| 模式 | 获得频率 | 每张时长 |
|---|---:|---:|
| 背书 | 每 20 分钟 | 2 分钟 |
| 自习 | 每 45 分钟 | 2 分钟 |

获得休息券时，屏幕右下角会出现一个独立小窗口，但不会替换主学习窗口。若主窗口正处于漂浮模式，漂浮窗会暂时移到休息提示上方；屏幕空间不足时移到左下角，提示关闭后回到原位置。你可以：

- 点击“立即休息”：消耗 1 张休息券并开始两分钟倒计时。
- 点击“攒着”：关闭提示；休息券保留在本次会话内，主界面的“休息（数量）”按钮可随时使用。

休息券可以累计，但只属于当前这场学习；结束学习或退出程序后不会带到下一场。动画、提醒或其他不能安全中断的状态结束后，休息按钮才会可用。

休息期间：

1. 有效学习时钟暂停。
2. 麦克风被释放。
3. 主窗口隐藏，右下角小窗显示倒计时。
4. 两分钟结束后，主窗口回到最前面。
5. 播放一次带源音轨的 `E1 → S1 → X1` 开场。
6. 重新打开麦克风：背书重新校准约 3 秒；自习直接恢复分类，约 2 秒后得到新的首窗结果。

## 10. 表扬与正常动画

表扬按有效学习时长触发：

- 背书模式：每 45 分钟一次。
- 自习模式：每 60 分钟一次。

达到里程碑后，下一次可见的正常巡查会优先播放“随机入场 → `R_pass_react_salute` → 随机退场”，并显示“已背书满 45 分钟”或“已自习满 1 小时”等字幕。字幕位于画面下侧，不遮挡教官和主按钮。窗口隐藏时不会为了普通巡查或表扬强行恢复前台；回到可见场景后再播放。

没有违规时，场景仍每隔 30～120 秒出现正常事件：

- 75% 为完整巡查：随机入场 → 正常观察 → 随机退场。
- 正常观察从 `R2_react_doubt`、`R_note_logbook`、`R_nod`、`R_close_check` 中选择。
- 25% 为独立事件：`L_lean`、`P_pass_corridor_red`、`P_pass_corridor_blue` 中的一段。

普通巡查、路过和观察全部静音，不会反复打断学习。

## 11. 动画与源音效规则

应用包含资源库中的 22 段动画和对应的 22 份源音轨。

自动播放源音轨的事件只有：

1. 开始学习的开场。
2. 结束学习的下班序列。
3. 三个等级的违规提醒。
4. 背书或自习里程碑表扬。
5. 休息结束后的开场。

每一段有声动画只播放它自己的源音轨，不生成、不替换、不叠加额外音效。普通巡查只是自动运行时静音；用户主动在动画库预览时仍播放该动画的源音轨。

动画切换前会预解码下一段并保留上一段末帧，避免中间清成黑屏。1280×720 源动画等比例放大到 1920×1080，不横向或纵向拉伸；屏幕可用区域不足时整体等比例缩小。

`R_fatigue_warning` 与 `X6_exit_abrupt` 保留在动画库供手动预览，但不进入自动播放池。

## 12. 完全隐藏、漂浮窗与提醒

在检测面板的“后台显示”选择：

- **完全隐藏**：主窗口从桌面和任务栏消失，只保留托盘；检测和有效学习计时继续。
- **漂浮窗**：原来的同一个主窗口缩为 320×225 并置顶，不新建窗口。常态只显示当前检测结果和下方 16:9 教官动画，不显示音量条、阈值、设置、日志或说明文字。

漂浮窗的使用方式：

- 把鼠标移到漂浮窗上，顶部才会显示“已学习 00:00”（本次有效学习时长），以及“隐藏”“放大”。移开后自动收起，只留下检测结果和动画。
- 点击“隐藏”切换为完全隐藏；点击“放大”回到完整主场景。
- 双击顶部状态区或动画也可放大；顶部空白区域可拖动漂浮窗。
- 背书状态直接显示“本人正在背书”“正在复核本人声音”“本人未出声 N 秒”等；自习状态直接显示“安静”“键盘输入”“疑似媒体声音 N 秒”等。它与主界面共用同一个判断结果，不另开检测。

共同规则：

- 只有正式学习会使用所选后台方式。还没开始学习、只在做“当前设置测试”时，进入后台会停止测试并释放麦克风。
- 不创建摄像头小窗，也不采集视频。
- 完全隐藏时普通巡查和表扬不会主动恢复主窗口；漂浮时正常教官动画继续在小画面中播放。
- 获得休息券时允许出现右下角独立提示窗。
- 发生违规时恢复原来的同一个主窗口并置顶，在原画布上连贯播放提醒；不会新建违规窗口。
- 第 1、2 次提醒后准确回到提醒前状态：此前完全隐藏就再次隐藏，此前是漂浮窗就再次缩回漂浮窗，此前在完整场景就留在完整场景。第 3 次提醒结束会话并留在前台。
- 提醒播放期间不能用最小化、最大化、托盘打开或 `Alt+F4` 绕过；若休息券提示当时可见，它会暂时收起，提醒结束后再恢复。

双击 Windows 通知区域中的“背书自习监督”图标可恢复主场景。右键托盘图标可选择打开督学场景、显示漂浮窗、完全隐藏或退出。只有“退出程序”才会彻底关闭应用。

## 13. 检测面板、重录与删除

点击“展开检测面板”可查看或操作：

- 当前检测状态与麦克风活动强度；自习显示原始 RMS，背书模式另显示环境底噪门槛。
- 开始前的“测试当前设置”；背书可试调时间与抗噪幅度，自习只试调媒体持续时间，均不产生正式提醒或学习记录。
- 背书模式的本机声纹状态、重新录入和删除。
- 背书模式的“重新校准环境底噪”；自习模式隐藏该按钮。
- 22 段动画与源音轨的手动预览。
- 本次学习记录。

删除声纹后，自习模式仍可直接使用；再次进入背书模式前必须重新录入。

## 14. 隐私与本地数据

- 不创建网络账号，不需要连接 `redwatch.top`。
- 不申请摄像头权限，不打开摄像头，不含人脸或手机识别。
- 麦克风 PCM 只在内存中处理，不保存成录音文件，也不上传；自习分类得到的标签和概率同样不写盘、不上传。
- 不包含音频文件导入声纹功能。
- 背书模式唯一持久化的麦克风衍生数据是使用当前 Windows 用户 DPAPI 加密的声纹：`%APPDATA%\背书自习监督\speaker-profile.dat`。同一 Windows 用户重启应用后可继续读取。
- 后台方式单独保存在 `%APPDATA%\背书自习监督\window-preferences.json`，内容只有 `hidden` 或 `floating`；不保存检测结果、学习时长、窗口文字、音频或个人信息。文件损坏时自动回到“完全隐藏”。
- 主界面和休息提示使用禁用 HTTP 缓存的内存会话。Electron 默认会话所需的临时文件被隔离到 `%APPDATA%\背书自习监督\TransientElectronData\run-<进程号>`，正常退出后由应用外的清理器删除；若程序意外中断，下次启动会先清理遗留目录。因此不会长期保留 `SessionData`、`Code Cache`、`GPUCache` 等浏览器运行缓存。
- 声纹档案使用当前 Windows 用户的系统加密能力；换电脑或换 Windows 用户通常需要重新录入。

从 1.10.0 或更早版本升级时，旧档案可能因旧加密实现无法打开；界面会明确提示“旧声纹需要重新录入”。这时录入一次即可，之后不应在每次启动时重复要求录入。1.12.0 的自习声音分类和漂浮窗不会读取或改写声纹档案。

安装版不会读取、复制或迁移旧便携版的声纹档案。首次使用时请按自己的日常麦克风环境重新录入一次；不要单独分享声纹数据目录。

## 15. 当前识别边界

本版本不做随机口令、活体检测或本人录音防重放；按用户要求，不额外加入这类限制。

普通游戏声、视频声和旁人说话在背书模式仍必须经过声纹匹配，但声纹识别属于概率判断，不能保证所有麦克风、回声、噪声和声音状态下 100% 准确。感冒、距离变化、麦克风更换或录入质量都会影响结果。

自习模式刻意不做声纹或程序来源识别。它只能分类麦克风实际听到的声音，不能检测静音播放的视频或只在耳机中播放的声音，也不能可靠区分课程与偷看的视频；合法课程、旁人说话等持续音频可能触发。极端响键盘、距离、扬声器方向和麦克风驱动处理仍可能造成漏判或误判。

## 16. 常见问题

### 本人背书却显示“暂未确认本人声音”

- 连续朗读几秒，不要只说一两个字。
- 保持与录入时相近的麦克风距离和音量。
- 打开检测面板，确认“麦克风”已选择当前设备；设备刚插拔时，先点击“刷新”。
- 换过麦克风、房间或声音状态变化明显时，切换麦克风后新增一份 24 秒声纹模板。
- 录入和背书时都不要让扬声器大声播放视频或音乐。

### 风扇让音量条变化

背书模式中，音量条变化不代表已经通过本人声纹。可让风扇保持日常转速，点击“测试当前设置”并等待约 3 秒校准；稳定风扇仍影响判断时再提高“抗噪幅度”。自习模式不创建或使用 `AdaptiveVad`，不做底噪校准、也没有抗噪门槛；原始 RMS 活动条仅用于确认麦克风是否收到声音，实际违规以本地声音标签为准。

### 自习时键盘会不会算违规

只识别到键盘标签时不会累计违规；键盘与两项媒体证据同时出现时仍会累计。模型已经针对真实键盘与媒体混音做离线回归，但不能保证每种键盘、麦克风和房间都完全一致。建议在开始前播放日常允许的键盘声并用“测试当前设置”试调；极端掩蔽仍可能漏判。

### 点击开始后麦克风不可用

进入“Windows 设置 → 隐私和安全性 → 麦克风”，允许桌面应用访问麦克风；关闭可能独占麦克风的会议、直播或录音软件后重试。启动失败时程序会安全回到待命并释放已经取得的麦克风资源。

### 正常巡查没有声音

这是设计行为。开场、结束、违规、表扬或休息恢复仍无声时，再检查 Windows 音量混合器中“背书自习监督”的音量和扬声器输出。

### 关闭窗口后程序仍在运行

正式学习中，关闭主窗口会按检测面板选择完全隐藏或显示漂浮窗，检测继续。待命状态会完全隐藏。请使用托盘菜单或页面上的“退出程序”彻底关闭。

### 搜索或任务管理器中出现多个同名 EXE

安装版不会像便携程序一样在 `%TEMP%` 解包出新的应用副本。Electron 仍会启动渲染、GPU 等辅助进程，因此任务管理器中可能看到多个同名进程；这不表示磁盘中保存了多个安装版。Windows 在程序运行时可能管理少量系统临时文件，但本应用不会持久保存浏览器缓存。

## 17. 结束学习

点击“结束本次背书”或“结束本次自习”后：

1. 麦克风立即释放，有效学习时钟停止。
2. 已经开始的完整动画序列会先收尾。
3. 播放有源音轨的 `E1 入场 → R_pass_react_salute → X1 退场` 下班序列。
4. 清空本次会话的提醒等级和休息券，回到待命场景。

如果动画解码或窗口恢复发生异常，程序会停止会话、释放麦克风、清除提醒遮罩并尽力恢复主窗口，避免卡在无法操作的界面。
